# Interfaz profesional — Aegis Auditor

La interfaz principal adopta una estructura tipo Security Operations Studio:

- barra lateral persistente;
- cabecera con identidad del producto y proyecto actual;
- panel de Inicio con estado, proyecto, perfil, proceso y hallazgos;
- navegación separada para Auditoría, IA, Medicinas, Evidencias y Registro;
- paleta oscura azul marino con acentos cian/turquesa;
- tablas, consolas y editores en modo oscuro;
- asistente de incorporación para generar perfiles config/*.json.

## Navegación

    Inicio
    Nuevo proyecto
    Cargar aplicación
    Auto-configuración
    Auditoría P1 + P2
    Correcciones con IA
    Recetas y conocimiento
    Evidencias
    Registro
    Reportes
    Configuración

La interfaz no cambia la metodología: todo diagnóstico sigue separado entre Pilar 1 y Pilar 2 y toda corrección debe verificarse antes de quedar aceptada.
